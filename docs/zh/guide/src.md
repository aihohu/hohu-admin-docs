# 源码与许可

**HoHu Admin** 官方开源项目默认采用 Apache License 2.0，另有声明的代码除外，遵守适用许可即可商业使用。欢迎大家 **Star**。

后端与 Web 从 v0.1.5 开始切换，v0.1.4 及此前已发布版本保留原 MIT 授权。其他项目直接在当前开发版本切换，不额外升版本；曾以 MIT 发布的内容，该授权对已分发副本继续有效。第三方代码保留适用的原许可与版权声明，详见各仓库 `LICENSE`、`NOTICE` 及适用的 `THIRD_PARTY_NOTICES.md`。

本文档站的许可文件：[Apache-2.0](/licenses/LICENSE.txt)、[项目声明](/licenses/NOTICE.txt)。

## 问题反馈与贡献

在对应组件仓库的 Issues 提交问题，提供版本、复现步骤、预期与实际结果及脱敏日志。命令问题优先提交 CLI 仓库，文档错误提交文档仓库。不要上传完整环境文件、账号凭据或业务数据。

修改前阅读目标仓库的 README、贡献规范与许可声明；本地开发入口见[开发指南](./development/)。发布变更见[版本与发布](./reference/versions)。
