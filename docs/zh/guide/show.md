# 在线演示

[打开 HoHu 演示环境](https://show.hohu.org)。可用功能取决于演示实例的配置和账号权限，登录信息以演示入口展示为准。

## 建议体验顺序

1. 浏览用户、角色和部门，了解业务账号与权限的组织方式。
2. 打开系统设置，查看品牌、账号、语言、文件与安全设置；操作前阅读[设置手册](./user/settings)。
3. 打开 AI 助手，查看可用助手。模型和工具由实例管理员配置，使用步骤见 [AI 助手](./user/ai)。

公共演示用于了解产品，请使用示例内容。需要保存自己的配置和数据时，使用 [CLI 创建本地环境](./quick-start)或[部署自己的实例](./deploy)。
