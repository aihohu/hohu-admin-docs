# 部署与运维

本指南面向安装和维护 **HoHu 应用实例** 的人员。默认采用 HoHu CLI 与 Docker Compose，包含 Web、API、独立 scheduler 以及可选的 PostgreSQL、Redis、Nginx。

## 首次上线

1. 确认[配套版本](../reference/versions)，按[使用 CLI 部署](../deploy)初始化配置、选择镜像和访问端口。
2. 配置[域名、代理与 HTTPS](./network)，检查证书、上传和 AI 流式响应。
3. 验证登录、权限、文件和任务，按[巡检与排错](./monitoring)建立日志与监控入口。
4. 保存部署版本与配置，完成一次[备份恢复演练](./upgrade)后再承载正式业务。

## 上线前确认

- 数据库和文件位于持久存储，恢复时所需密钥已保管。
- 后端与 Web 版本配套，数据库迁移成功，普通账号权限符合预期。
- 域名指向预期实例，HTTPS 有效，管理和监控端口只对需要的网络开放。
- API 与 scheduler 职责分开，AI worker 模式与部署数量一致。
- 注册与找回密码按租户设置启用，邮件服务已验证；见[系统设置](../user/settings)。

CLI 编排启动与迁移，不自动完成数据库备份、证书续期验证或业务验收。已有实例先阅读升级步骤，不把首次安装操作当作重置流程。
