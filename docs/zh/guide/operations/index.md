# 部署与运维

本部分面向负责安装、配置和维护系统的人员。项目使用 hohu-cli 编排服务，用户不需要逐个执行初始化脚本。

- 首次安装：阅读[版本说明](../reference/versions)，准备 Docker 环境，按 [CLI 部署](../deploy)配置并启动。
- 已有系统：先阅读[升级、备份与恢复](./upgrade)，确认升级起点和配套版本。
- 多业务租户：按[多租户管理](./tenants)启用并开通租户，不能仅修改登录页面。
- 启用 AI：按 [AI 配置](./ai)设置模型、出站策略、权限与进程模式。

数据库、Redis、密钥、网络和存储属于部署配置；品牌、注册、语言和业务上传偏好属于系统设置。完整归属见[配置项参考](../reference/configuration)。
