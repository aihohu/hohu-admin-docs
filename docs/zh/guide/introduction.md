# HoHu 开源 AI 企业应用平台介绍

HoHu 是面向 AI 原生业务应用的开源企业应用平台。它把业务界面、AI 能力、权限与数据组织在一起，帮助团队构建和运行自己的业务应用。

## HoHu 适合谁

HoHu 面向使用 Python 和 Vue 开发业务应用、希望掌握源码与部署环境的开发者和团队。后端采用 FastAPI，Web 界面采用 Vue 3，也可以通过 [HoHu Skills](./cli/skills) 让编程助手辅助创建项目和实现业务模块。

创建应用需要开发环境和业务代码。HoHu 不是无代码搭建工具，也不是开箱即用的 CRM、ERP 或审批套件。你可以先[体验现有平台](./show)，再按[快速开始](./quick-start)在本地运行，或了解如何[为业务接入 AI 工具](./development/ai-tools)。

## 你可以用它做什么

- **构建业务应用**：复用用户、组织、权限、文件、任务与设置，开发自己的模型、接口和业务页面。
- **在应用中使用 AI**：通过对话查询数据或发起受控业务操作，遵循账号已有的权限与数据范围。
- **在自己的环境运行**：通过 CLI 创建、开发、构建和部署项目，掌握源码与数据。

HoHu 提供应用基础；CRM、库存或运营系统可以基于它开发，并不意味着这些完整业务套件已经内置。当前能力以对应操作手册为准。

## 项目组成

| 仓库                 | 职责                                             |
| -------------------- | ------------------------------------------------ |
| `hohu-admin`         | 后端与平台核心，包含业务 API、认证权限和 AI 服务 |
| `hohu-admin-web`     | Web 应用界面                                     |
| `hohu-cli`           | 项目创建、初始化、开发、构建与部署工具           |
| `hohu-admin-app`     | 移动端客户端                                     |
| `hohu-admin-desktop` | 桌面端客户端                                     |
| `hohu-admin-docs`    | HoHu 官网与文档                                  |

仓库名称中的 Admin 沿用项目名称；官网和平台整体品牌为 **HoHu**。源码及授权说明见[源码与许可](./src)。
