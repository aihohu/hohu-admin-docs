# 使用指南

本指南面向使用已部署系统的人员，不要求编写代码或执行数据库脚本。

1. 从管理员取得访问地址、账号和所属租户，按[账号与登录](./account)进入系统。
2. 管理员按[用户、角色与部门](./access)分配权限；普通用户只会看到被授权的功能。
3. 系统管理员在[系统设置](./settings)中调整品牌、账号、语言和文件策略；业务参数在[自定义参数](./parameters)中管理。
4. 使用[文件上传](./files)和 [AI 助手](./ai)前，确认账号具有对应权限。

无法访问时先看[常见问题](./faq)。需要自行安装系统，请进入[部署与运维](../operations/index)；需要增加业务功能，请进入[开发指南](../development/index)。
