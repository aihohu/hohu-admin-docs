# 使用指南

本指南面向使用已部署 HoHu 的人员。请先向管理员确认站点地址及所属租户；需要自行安装系统时，查看[部署与运维](../operations/index)。

## 第一次使用

1. 打开正确的站点，使用管理员提供的账号登录；站点开放注册时也可自行注册。
2. 在个人账户中检查资料和恢复邮箱。管理员分配的初始密码应及时修改。
3. 从菜单进入已授权的业务应用。注册成功不代表已获得业务权限；没有业务菜单时联系管理员分配角色。
4. 遇到问题先查看[常见问题](./faq)，反馈时附上操作步骤和错误提示。

## 管理员从哪里开始

先按[成员与权限配置](./access)建立部门、配置角色，再创建用户。批量录入前准备部门及角色，下载最新导入模板；开放注册前先完成[邮件服务与账号自助服务](./settings#account-self-service)配置。

页面和操作按钮取决于当前账号权限。普通用户无需操作系统设置，也无需获取部署配置文件。

了解产品定位可阅读[项目介绍](../introduction)，试用可访问[在线演示](../show)。业务扩展与代码接入请进入[开发指南](../development/index)。
