# 系统设置

系统设置用于调整 HoHu 的内置行为。你可以修改网站名称与 Logo、注册开关、默认语言和上传限制，无需改动源码。

进入 **系统管理 → 系统设置**。需要查看权限；保存设置还需要编辑权限。业务自己定义的键值参数在独立的[自定义参数](./parameters)页面管理。

[![系统设置的品牌与外观页面](/images/product/settings-brand-zh.png)](/images/product/settings-brand-zh.png)

## 保存与生效

1. 选择要修改的分组，例如“品牌与外观”。
2. 修改字段，点击 **保存当前设置**。
3. 页面显示保存成功后，检查实际界面是否符合预期。

每次保存只提交当前分组。切换分组会保留尚未保存的草稿；离开页面时如有未保存修改，会出现提醒。品牌、语言等客户端配置会在保存后刷新，其他已打开的客户端可能需要刷新页面。

设置通常作用于当前租户。访问保护属于系统级配置，仅默认租户的系统管理员可以管理。

## 品牌与外观

| 字段      | 用途                                   |
| --------- | -------------------------------------- |
| 网站名称  | 设置界面使用的站点名称                 |
| 网站 Logo | 配置 Logo 地址，或通过上传按钮选择图片 |
| 网站描述  | 提供简短的站点介绍                     |
| 备案信息  | 填写站点需要展示的备案文字             |
| 页脚信息  | 配置页面底部文字                       |

例如，把“网站名称”改为团队自己的应用名称，保存后检查界面展示。Logo 使用可访问的图片地址，上传时仍受图片格式和大小限制。品牌文字按原文保存，不随界面语言自动翻译。

## 账号与用户

| 字段                 | 作用                                   | 使用建议                                   |
| -------------------- | -------------------------------------- | ------------------------------------------ |
| 默认头像             | 未单独设置头像时使用的图片             | 使用稳定、可访问的图片地址                 |
| 开放注册             | 控制注册入口与注册行为                 | 内部使用的系统可关闭注册，由管理员创建账号 |
| 用户必须有所属主部门 | 约束用户的部门归属                     | 启用前先完善部门结构与已有用户归属         |
| 默认密码             | 供支持默认密码的账号创建或导入流程使用 | 使用符合系统密码规则的值，定期审查使用流程 |

密码字段不显示原值。留空保存表示保留已有密码，不表示清除。这里的默认密码不会修改已存在用户的密码。

## 语言与地区

默认语言用于尚未主动选择语言的用户。语言选择优先级为：**用户选择 → 租户默认 → 部署默认**。

目前可选中文和英文。切换语言会翻译界面标签及绑定翻译资源的内置名称；你输入的品牌、部门名称、协议正文和自定义参数保持原文。

## 文件上传

[![系统设置的文件上传页面，大小单位为 MiB](/images/product/settings-files-zh.png)](/images/product/settings-files-zh.png)

| 字段             | 说明                             |
| ---------------- | -------------------------------- |
| 单文件大小上限   | 当前租户对上传文件的通用大小限制 |
| 图片大小上限     | 图片场景使用的大小限制           |
| 表格导入大小上限 | 表格导入场景使用的大小限制       |
| 允许的文件扩展名 | 当前租户允许使用的格式集合       |

页面以 **MiB** 显示大小，1 MiB = 1,048,576 字节。三个大小字段初始均为 10 MiB。

例如，想把图片限制为 5 MiB，将“图片大小上限”设为 `5` 后保存。新图片上传会使用此限制；已有文件不会因降低额度而被删除。

最终可上传大小还受服务器硬上限和业务场景处理上限约束。扩展名同样需要同时被租户和业务场景允许：选择了 PDF 不意味着头像上传支持 PDF。详见[文件与上传](./files)。

## 协议内容

维护用户协议与隐私政策正文。保存前确认内容适用于当前站点；正文属于你维护的业务内容，不会自动翻译。修改协议不会代替你对外履行必要的告知流程。

## 访问保护

| 配置                | 默认值 | 可配置范围 |
| ------------------- | ------ | ---------- |
| 每分钟登录请求额度  | 5      | 1–100      |
| 每分钟注册请求额度  | 3      | 1–30       |
| 每分钟 API 请求额度 | 100    | 10–10,000  |

这些值控制相应请求的速率限制，并不表示全站最多只能拥有这么多用户。调小数值可能影响正常操作；应结合使用情况调整。请求超过额度会返回 429，按返回的重试时间稍后再试。

## 常见问题

**为什么看不到保存按钮或无法编辑？** 确认角色具有系统设置编辑权限。自定义参数权限与系统设置权限相互独立。

**为什么看不到访问保护？** 该分组仅对默认租户的系统管理员开放。

**提示设置被其他人修改怎么办？** 先记下自己的修改，重新加载最新设置，再合并后保存。系统通过版本校验避免覆盖其他管理员的更新。

**数据库、Redis、模型密钥在哪里配置？** 部署连接由部署者维护；AI 模型在 AI 管理中配置。参阅[配置项归属](../reference/configuration)和 [AI 配置](../operations/ai)。
