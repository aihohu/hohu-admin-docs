# 用户、角色与部门

本页面向拥有用户、角色或部门管理权限的管理员。三类管理权限可以分别授权，能查看列表不代表能修改。

## 配置顺序

1. 在部门管理中建立需要的部门层级，再维护用户的部门归属。
2. 在角色管理中创建或选择角色，分配菜单与按钮权限。
3. 为角色选择数据范围：全部、本部门、本部门及以下、自定义部门或仅本人。自定义范围需要选择具体部门。
4. 将角色分配给用户，检查用户及角色处于启用状态。
5. 用普通测试账号核对可见菜单、可操作按钮和可见记录；不要只用超级管理员验收。

## 数据范围如何合并

多个启用角色的实际范围取并集。例如一个角色允许本部门，另一个允许指定部门，用户可以看到两者授权的数据；不是简单按某个数字等级取一个角色。全部数据仍指所属租户的数据。

默认租户的系统超级管理员可以执行获准的系统管理操作；其他租户的管理员只管理所属租户。角色权限不等于 AI 助手授权，AI 还需要显式入口权限、助手绑定和工具权限。

看不到预期记录时检查部门、角色状态和数据范围。看不到菜单时检查菜单授权及是否已刷新会话信息。代码接入方式见[接口权限](../auth)与[数据范围](../data-permission)。
