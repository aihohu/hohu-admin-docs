# 自定义参数

自定义参数用于业务扩展的配置值，不用于修改产品内置的登录、上传和限流设置。需要对应参数管理权限。

1. 打开自定义参数列表，查询已有键，避免重复创建。
2. 根据业务模块约定填写键、值及允许编辑的属性。只有业务代码读取该键时，参数才会影响功能。
3. 保存后在对应业务流程验证；修改或删除前确认没有其他模块依赖该参数。

不要使用内置键或 AI、安全、上传等保留命名空间绕过系统设置校验。系统设置保存于 `sys_setting`，自定义参数保存于 `sys_config`，删除业务参数不应改变内置设置。

公开参数可能被未登录客户端读取，不要把凭据或个人敏感信息配置为公开。导入和导出也只能操作自定义参数，不用于批量改写内置设置。

品牌、注册、语言、上传额度请进入[系统设置](./settings)。
