# 自定义参数

进入 **系统管理 → 自定义参数**。需要对应查看权限；新增、编辑、删除、导入和导出分别授权。

参数用于业务模块约定的配置值。只有业务代码读取对应键时才会影响功能，添加参数不会自动创建功能。品牌、账号、语言、邮件和上传策略应在[系统设置](./settings)管理。

## 创建参数

1. 按参数名称或键查询，确认没有重复项。
2. 点击新增，按业务模块的配置约定填写字段。
3. 保存后到使用该参数的业务页面验证结果。

| 字段     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| 参数名称 | 供管理员识别的名称                                         |
| 参数键   | 业务代码读取的唯一标识；与开发者约定保持一致               |
| 参数值   | 按业务模块要求填写的值                                     |
| 参数类型 | 文本、富文本或文件；类型本身不会自动生成业务界面           |
| 参数分组 | 便于按模块归类和查询                                       |
| 状态     | 启用或停用；停用后的具体业务表现取决于读取方式及默认值     |
| 是否公开 | 公开参数可能被未登录客户端读取，不应包含凭据或敏感个人信息 |
| 备注     | 说明用途、取值规则及使用该参数的模块                       |

例如，**如果你的业务模块已约定读取** `orders:notice`，可按该约定配置订单页公告。这个键仅为示例，HoHu 不会因添加它而自动显示公告。

## 修改、停用与删除

查询目标参数后点击编辑，保存新值并在业务页面验证。更改参数键、停用或删除前，应确认依赖模块如何处理缺失值。

内置配置键以及 AI、安全、上传等保留命名空间不能作为普通业务参数改写。遇到保留键提示时，转到对应设置入口。

## 导入与导出

从列表使用导出获取 XLSX 文件，导入时保留其列顺序并按页面提示处理结果。导入只新增参数，已存在的键和内置保留键会跳过，不会覆盖更新。两项操作仅用于业务自定义参数，不用于迁移系统内置设置。脱敏导出值不等于完整备份，导入后仍需逐项验证实际效果。

## 常见问题

**保存成功但没有变化？** 确认业务模块读取了这个键，核对拼写、当前租户、启用状态及业务缓存刷新方式。

**能查看但不能编辑？** 参数管理权限与系统设置权限不同，请联系管理员分配对应操作权限。
