# 用户管理

进入 **系统管理 → 用户管理**。查看、新增、编辑、角色分配、重置密码和删除分别需要对应权限；可管理对象还受数据范围限制。

## 创建用户

1. 点击新增，填写用户名、昵称及初始密码。
2. 按需填写性别、手机号和邮箱，选择启用或停用状态。
3. 有角色分配权限时选择业务所需角色。列表只提供当前账号可分配的角色，可输入名称或标识查找。
4. 有部门相关权限时选择所属部门，并从所选部门中确认一个主部门。系统要求主部门时必须完成归属配置。
5. 保存后在列表查询新用户，核对角色、部门和状态，再交付登录信息。

批量创建参阅[用户导入与导出](./user-import-export)。用户也可在开放注册的站点自行注册，再由管理员补充业务角色与部门。

## 编辑资料和授权

查询目标用户并点击编辑，修改资料、状态或具有权限的角色与部门字段。角色决定业务功能和数据范围，部门归属参与数据范围计算，详见[角色与权限](./roles)。

保存涉及资料、角色和部门多项变更时，若出现“部分更新”提示，请重新打开该用户，检查已经保存的内容后再处理剩余项，避免假定全部成功或全部失败。

管理员填写或修改邮箱不会代替本人验证；用户须到[恢复邮箱](./account#recovery-email)完成验证后才能用它找回密码。

## 重置密码 {#reset-password}

1. 核对目标用户的用户名及所属租户。
2. 点击该行的重置密码操作，输入符合规则的新密码并确认。
3. 通过适当渠道将新密码交给本人，请其登录后自行修改。

账号停用与密码错误是不同问题。重置密码不会自动恢复停用账号；邮箱自助找回流程见[忘记密码](./account#reset-password)。

## 停用与删除

暂时禁止访问时，在编辑中将用户状态设为停用并保存。需要恢复时，在确认业务授权后重新启用。

删除需要额外权限并受保护规则限制。先确认用户名和业务关联，再使用单行删除或勾选后的批量删除。系统拒绝删除时应按提示处理，不能以改名或更换角色绕过保护。

## 常见问题

**找不到角色或用户？** 检查搜索条件、角色启用状态和当前账号的可管理范围。

**能编辑用户，但不能分配角色？** 用户编辑与角色分配是独立权限，请联系有授权能力的管理员。

**保存后仍看不到业务菜单？** 检查角色的菜单授权、启用状态及用户实际角色，刷新页面或重新登录后验证。
