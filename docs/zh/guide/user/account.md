# 账号与登录

准备好站点地址及所属租户。已有账号可直接使用密码登录；注册和邮箱找回密码是否可用，由当前租户策略及邮件服务共同决定。

## 登录 {#sign-in}

1. 打开管理员提供的站点地址。
2. 若页面显示租户代码，填写管理员提供的代码；使用租户域名时进入对应域名。默认租户与业务租户的账号不能混用。
3. 输入**用户名和密码**，点击确认。
4. 登录后检查身份和可用菜单。只有个人账户入口时，联系管理员分配业务角色。

当前登录页使用密码登录，不提供短信验证码登录或“记住我”选项。用户名为 `admin` 不会自动获得管理员权限。

## 注册账号 {#register}

**前提：** 登录页显示“注册账号”，且你能接收注册邮箱的邮件。注册只在当前租户内创建账号，不会新建租户。

1. 点击 **注册账号**，填写用户名和邮箱。
2. 点击 **发送验证码**，到该邮箱查收邮件。
3. 填写六位验证码，设置新密码并再次确认。按页面提示满足用户名与密码规则。
4. 提交成功后返回登录页，使用刚创建的用户名和密码登录。

注册邮箱会完成验证。新用户默认仅能使用个人账户；管理员可为新注册用户配置一个本租户的非管理角色。需要其他业务权限时联系管理员。

没有注册入口或提示服务不可用时，向管理员申请账号。管理员配置方式见[账号自助服务](./settings#account-self-service)。

## 维护个人账户 {#profile}

从账户菜单进入个人账户页面（个人中心）。

| 操作         | 步骤与结果                                                         |
| ------------ | ------------------------------------------------------------------ |
| 修改资料     | 在“基本信息”修改昵称、性别或手机号，点击确认保存；用户名在这里只读 |
| 修改头像     | 点击头像，选择预设头像或上传图片，确认后检查显示效果               |
| 修改邮箱     | “基本信息”中的邮箱只读；通过“恢复邮箱”验证新地址                   |
| 修改密码     | 在密码页签填写旧密码、新密码及确认密码，保存成功后重新登录         |
| 切换显示语言 | 使用语言选择入口；语言切换不会翻译自己填写的姓名或业务内容         |

## 验证或更换恢复邮箱 {#recovery-email}

**前提：** 已登录、知道当前密码，且邮件服务可用。

1. 打开 **个人账户 → 恢复邮箱**，查看是否已验证。
2. 填写要使用的邮箱和当前密码，点击发送验证码。
3. 到该邮箱查收邮件，填写六位验证码并提交验证。
4. 确认页面显示“邮箱已验证”。以后找回密码时使用此邮箱。

历史账号已有邮箱，不代表邮箱已经验证。管理员修改或导入更新邮箱后，也需要用户重新验证。邮箱不可用但仍能登录时，应先更换恢复邮箱。

## 忘记密码 {#reset-password}

**前提：** 登录页显示“忘记密码”，账号处于启用状态，并已验证可接收邮件的恢复邮箱。

1. 在正确租户的登录页点击 **忘记密码**。
2. 填写用户名及该账号已验证的邮箱，发送验证码。
3. 查收邮件，填写验证码、新密码和确认密码，提交。
4. 重置成功后使用新密码登录。该账号的旧会话全部失效，其他设备也需要重新登录。

发送后页面会显示统一提示；只有账号与已验证邮箱匹配时才会收到恢复邮件。提示出现不代表账号匹配或邮件已经送达。

没有已验证邮箱、无法接收邮件、账号停用或找回入口不可用时，联系有权限的管理员处理，参阅[管理员重置密码](./users#reset-password)。

## 验证码问题 {#verification-code}

- 检查邮箱拼写、当前租户、垃圾邮件及邮件延迟。
- 验证码默认有效期为 5 分钟，实际以页面提示为准。倒计时结束后再重发，通常需等待 60 秒。
- 重发后使用最新验证码；注册、邮箱绑定和找回密码的验证码不可混用。
- 更改用户名、邮箱或租户后，应重新发送对应验证码。连续校验失败或触发限流时按提示等待。

仍无法完成时，提供操作时间、错误提示和脱敏截图，交由管理员排查[邮件服务](./settings#mail)。不要发送密码或验证码。
