# 账号与登录

## 登录

1. 打开部署方提供的站点地址。
2. hosted 部署按管理员提供的租户代码或租户域名进入。默认租户与业务租户的账号不能混用。
3. 输入账号和密码。是否允许注册由系统设置决定；没有注册入口时向管理员申请账号。
4. 登录后确认显示的身份与可用菜单，使用个人信息入口维护自己的资料，使用语言选择入口切换显示语言。

用户名 `admin` 不会自动授予管理员权限。权限由启用的角色决定；修改管理员账号名称不会因此失去角色权限。

## 密码与首次安装

初始管理员密码由 CLI 生成，部署者从受保护的 `.hohu/deploy/.env` 获取；本地开发使用后端 `.env`。普通用户向管理员领取账号，不应获得整个配置文件。首次使用后及时修改初始密码。

忘记密码时联系有权限的管理员重置。账号停用、租户停用或权限撤销不能通过反复登录绕过。不要在问题反馈中提供密码、Token 或完整配置文件。

页面显示语言不会翻译自己输入的姓名、品牌或业务内容，详见[系统设置](./settings)。
