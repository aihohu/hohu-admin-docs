# 部门管理

进入 **系统管理 → 部门管理**。查看、新增、编辑和删除需要对应权限；成员管理还需要用户相关权限。

## 建立部门层级

1. 点击新增建立部门，或在已有部门行点击 **新增子部门**。
2. 选择上级部门，填写部门名称、排序、负责人、联系方式和状态。
3. 确认保存，在部门树中检查层级和名称。

先建立上级部门再建立下级部门。负责人信息不等于自动授予管理权限；实际权限由角色和授权范围决定。

## 修改部门资料

查询部门后点击编辑，维护名称、排序、负责人、电话、邮箱和状态。当前 Web 编辑操作不提交上级部门变更，不能通过普通编辑移动部门层级。

部门层级与成员关系会影响相关用户的数据范围，修改后应使用受影响的普通账号验证。

## 维护成员 {#members}

1. 在部门行点击 **成员管理**。
2. 在候选用户中查找要加入的人员，将其移到部门成员列表；将可移除的成员移回候选列表。
3. 确认保存，重新打开检查成员结果。

成员管理入口需要部门查看、部门编辑、用户查看和用户编辑权限。候选人员还受当前账号的数据范围限制。

以该部门为主部门的成员不能在此直接移除。先在[用户管理](./users)中调整所属部门及主部门，再处理成员关系。用户可以属于多个部门，但所选部门中需明确主部门。

## 删除部门

当前 Web 删除入口要求超级管理员身份及对应删除权限。有下级部门、直接成员或角色数据范围引用时，系统会阻止删除。

先调整成员及角色引用，再从叶子部门逐项核对。删除部门不会自动把成员迁移到其他部门。

## 常见问题

**看不到成员管理？** 检查上文所列的四项权限。

**候选列表没有某位同事？** 检查账号状态、当前管理员的数据范围及查询条件。

**成员被锁定无法移除？** 确认该部门是否为其主部门，并先从用户编辑中修改归属。
