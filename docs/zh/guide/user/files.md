# 文件与上传

进入 **系统管理 → 文件管理** 查询已记录的文件。查看、上传及删除需要对应权限。业务导入、头像和 AI 附件使用各自的上传入口，不应把文件管理列表当作所有附件的统一下载入口。

## 查询与上传 {#upload}

1. 按文件名或文件类型搜索，检查文件名、大小、上传人及时间。
2. 点击 **上传文件**，选择或拖入文件，先查看当前入口允许的格式和大小。
3. 等待上传成功，关闭窗口后在列表核对记录。业务表单中的文件应上传成功后再提交表单。

文件管理当前使用通用公开上传，实际按 JPEG/PNG 图片内容校验。不能仅根据文件选择器或系统设置里出现某种扩展名，就认定此入口支持该格式。

## 复制链接与删除 {#manage}

使用文件行的 **复制链接** 获取可用链接；复制失败时检查浏览器剪贴板权限及站点 HTTPS。公开图片链接用于可公开展示的资源，私有业务附件应通过对应业务入口访问。

删除前检查文件是否仍用于头像、Logo 或业务内容。确认后可单行删除，或勾选后批量删除。删除会移除文件记录并尝试删除存储文件，已有页面引用可能因此失效；它不是从列表中隐藏记录。

## 不同入口支持什么 {#formats}

| 入口               | 当前支持与条件                                               |
| ------------------ | ------------------------------------------------------------ |
| 通用公开上传、图片 | 按 JPEG/PNG 内容校验；通用非图片文件尚无完整的存储和下载通道 |
| 用户导入           | XLSX、CSV，使用[用户导入流程](./user-import-export)          |
| Web AI 数据附件    | CSV、XLSX、Markdown、JSON，需通过解析与预算检查              |
| Web AI 图片        | PNG、JPEG，需要可用的图片理解模型                            |

后端解析器另支持部分 TXT 类型，不表示 Web AI 入口接受 TXT。详见 [AI 附件](./ai#attachments)。私有附件按所属用户和租户鉴权，拿到文件 ID 或路径不等于可以访问。

## 大小限制与失败处理 {#limits}

有效单文件上限取部署硬上限、租户策略和业务场景上限中的最小值。多文件请求还受整个请求体大小限制，单个文件合规不保证整批合规。

| 提示                 | 处理方式                                       |
| -------------------- | ---------------------------------------------- |
| 格式或内容不支持     | 换用当前入口支持的真实文件格式，不要仅修改后缀 |
| 文件过大             | 减小文件或拆分内容，按页面显示的限制重试       |
| 413                  | 请求可能超过代理或服务器硬上限，联系部署者核查 |
| 无权限或无法访问附件 | 核对当前账号、租户和附件所属业务入口           |

管理员可在[系统设置](./settings)调整普通额度和白名单，不能突破部署或解析器边界。
