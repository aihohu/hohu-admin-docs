# 文件与上传

上传入口根据用途限制文件类型和大小。文件管理、图片、业务导入和 AI 附件不一定接受相同格式。

## 上传步骤

1. 在实际业务页面选择上传入口，先查看允许格式和大小。
2. 选择文件，等待成功结果后再提交依赖该文件的表单。
3. 失败时查看大小、格式和内容提示。不要只修改文件后缀来绕过校验。

有效单文件大小是部署硬上限、租户设置和场景上限的最小值。多文件请求还受到整个请求体大小限制，单个文件合规不保证整个批次合规。

## 当前格式边界

- 图片、业务导入和 AI 文本附件各有独立白名单。
- AI 文本附件支持 csv、xlsx、txt、md、json；具体内容仍须通过解析检查。
- 系统设置里可选择的扩展名全集，不表示所有上传入口都支持这些格式。当前通用公开上传按 JPEG/PNG 内容校验，通用非图片文件尚无完整的存储和下载通道。
- 私有附件按所属用户和租户鉴权，拿到文件 ID 或路径不等于可以访问。

提示 413 时可能触发了代理或请求体硬上限；请联系部署者。普通额度和白名单由管理员在[系统设置](./settings)调整，不能超过部署及解析器的安全边界。
