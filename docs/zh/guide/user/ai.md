# AI 助手

使用前需要部署者配置可用模型，并由管理员授予 AI 入口权限、角色与助手绑定、工具权限。能登录、拥有超级管理员角色或看到 shared 标记，都不代表自动获得全部 AI 能力。

## 开始对话

1. 打开 AI 助手，选择当前账号可用的助手并开始对话。
2. 清楚描述要查询或修改的对象。涉及文件时从附件入口上传，遵守[文件限制](./files)。
3. 助手准备执行需要确认的操作时，核对对象、范围和参数；确认后才允许执行。取消或过期后不能继续使用旧确认。
4. 根据实际执行结果判断是否完成，不把模型生成的文字当成修改成功凭证。

权限或租户状态变化后，旧结果、附件或待确认操作可能不再可访问；这是当前授权校验，不应通过复制旧链接绕过。确认不表示任务一定能在浏览器断开后继续执行。

没有可用助手或模型时联系管理员；服务提示 AI 已关闭时联系部署者。部署和授权排查见 [AI 配置与运维](../operations/ai)。

## 界面示例

![AI 助手起始页，可选择助手并输入任务](/images/product/ai-assistant-zh.png)

首次体验可以从“查询我有权限查看的用户”这类只读任务开始。明确查询条件后，检查返回内容；需要修改时，先说明目标和变更值，再核对确认卡片。具体可用操作由当前助手绑定的工具决定。

## 常见情况

| 情况                       | 处理方式                                     |
| -------------------------- | -------------------------------------------- |
| 没有助手可选               | 请管理员检查助手启用状态和角色绑定           |
| 可以聊天但不能执行业务操作 | 检查助手工具绑定及当前账号的业务权限         |
| 确认失效                   | 重新发起任务并审核新的确认，不重复提交旧卡片 |
| 附件上传失败               | 检查格式和大小限制，必要时参考文件手册       |
| 模型无响应                 | 由部署者检查模型连接、凭据与服务日志         |
