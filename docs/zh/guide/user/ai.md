# 使用 AI 助手

本页面向已运行 HoHu 应用的用户。AI 助手通过当前账号获准使用的业务工具完成任务；首次配置模型与授权见 [配置与运维](../operations/ai#first-setup)。通过编程助手开发应用见 [AI 辅助开发](../ai-coding)。

## 开始一次查询 {#first-query}

1. 打开 **AI 对话**，新建对话，检查是否有可用模型和助手。
2. 选择一个模型。使用 **AI 自动路由**，或手动选择“用户管理助手”等对应业务助手。
3. 输入明确的查询，例如“查询我有权限查看的启用用户”。按发送按钮或 Enter 发送；Shift+Enter 换行。
4. 查看实际工具执行记录与结果。继续追问时补充筛选条件，例如“只看销售部门”。遇到不确定的对象或任务类型，按助手的澄清提示补充。

查询结果受账号的数据范围限制，并不代表全系统数据。缺少助手或模型时，按下方排错表联系管理员。

## 选择助手和模型 {#selection}

| 选项         | 如何使用                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| AI 自动路由  | 根据当前问题与近期对话选择已授权的助手，支持连续追问和切换话题；无法确定时可能要求选择任务类型       |
| 手动选择助手 | 已知道业务范围时直接选择，例如用户管理、部门管理；具体能力见 [当前内置助手](../ai/index#application) |
| 模型         | 只能选择当前租户获准使用且适合对话的模型；模型不可用时刷新选项或联系管理员                           |

自动路由不会增加你的业务权限。安装 Skills、拥有超级管理员角色或看到 `shared` 标记，都不代表能调用全部业务工具。

> 将用户“example-user”的昵称改为“设备管理员”。

需要确认的操作会展示确认卡片或抽屉：

1. 核对目标对象、变更值、影响范围和有效期。批量、授权或删除操作尤其要核对完整集合及影响数量。
2. 内容正确时确认执行；有误则取消，并重新描述任务。过期或已处理的确认不能重复使用。
3. 等待工具显示实际执行结果，再刷新对应业务页面确认变更。

确认失败或网络断开时，先恢复连接、刷新会话并核对执行状态；状态不明时不要直接再次提交写入。显示仍在执行时，具备权限的用户可到 AI Trace 查看。确认不保证浏览器断开后任务一定继续完成。

创建单个用户时，是否必须指定主部门由当前租户的「系统设置 → 用户必须分配主部门」决定。关闭时可以说“创建普通用户 hohu，不分配部门”；开启时助手会根据预检结果要求补充有效部门。指定部门需要相应查询权限和数据范围，创建前仍需确认。此规则不改变文件导入的部门列要求。

## 查看结果 {#results}

| 界面内容           | 表示什么                                                               |
| ------------------ | ---------------------------------------------------------------------- |
| 助手文字           | 对任务的解释和摘要，应结合工具记录核实                                 |
| 工具执行卡         | 展示执行中、等待确认、成功或失败；失败时查看原因                       |
| 列表、统计或详情卡 | 展示工具返回的数据；摘要或预览可能不包含全部记录                       |
| 查看完整数据       | 仅部分工具提供，跳转到相应业务页面并回放受支持的筛选条件               |
| 下载文件           | 仅产生文件的工具提供；下载仍校验权限，失效时按提示重新导出或联系管理员 |

权限、租户状态或对象变化后，旧结果和附件可能不可访问。当前授权校验仍适用于历史对话。

## 文件和图片 {#attachments}

从附件入口选择文件，或将文件拖入输入区；等待上传完成后再发送。移除附件可取消本次消息对它的引用。

| 当前 Web 附件格式                   | 准备条件与结果                                                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 数据文件：CSV、XLSX、Markdown、JSON | 当前账号有可用通用工具助手、`ai:file:parse` 权限及已启用的 `file.parse`；工具返回结构摘要和有限预览，不表示读取所有行 |
| 图片：PNG、JPEG                     | 需要可用的图片理解（`vision`）模型；没有时移除图片或联系管理员配置                                                    |

发送图片时，系统可能切换到可用的图片理解模型，以界面提示为准。模型能力声明不能代替真实调用验证。格式、大小和访问限制见 [文件与上传](./files)；文件解析策略见 [配置与运维](../operations/ai#file-parsing)。

## 历史对话与停止回复 {#history}

- 新任务可以点击“新对话”，历史对话可按标题搜索并重新打开。
- 删除对话需确认，删除后不可恢复；删除对话不会撤销已完成的业务操作。
- 停止回复会中止当前回复接收，不等于取消待确认操作或回滚已执行的修改。取消操作应使用对应确认卡片。
- 当前不提供历史消息编辑重发和重新生成；需要修改需求时发送新消息，或开启新对话。

## 常见问题 {#troubleshooting}

| 现象                         | 处理方式                                                           |
| ---------------------------- | ------------------------------------------------------------------ |
| 没有 AI 对话入口或提示无权限 | 检查 AI 对话菜单和 `ai:chat:use` 权限                              |
| 没有助手可选                 | 管理员检查助手启用状态、角色绑定及有效工具权限                     |
| 没有可用模型                 | 检查当前租户模型授权、模型文本能力、模型与 Provider 状态及出站连接 |
| 可以聊天但不能处理业务       | 确认所选助手提供该操作，并检查业务权限及数据范围                   |
| 文件不能上传或解析           | 检查格式、大小、通用工具助手、文件解析权限和工具策略               |
| 图片无法识别                 | 检查是否有可用 vision 模型；必要时移除图片后发送文本               |
| 确认过期                     | 重新发起任务，核对新确认；不重复使用旧卡片                         |
| 确认请求失败或执行状态不明   | 恢复连接，刷新会话并检查工具或业务页面状态，再决定是否重试         |
| 旧结果或附件不可访问         | 检查当前授权及对象状态，不通过旧链接绕过权限                       |
| 模型无响应或 AI 已关闭       | 联系部署者检查模型连接、服务日志及 AI 开关                         |
