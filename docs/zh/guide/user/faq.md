# 常见问题

| 现象                       | 首先检查                                             |
| -------------------------- | ---------------------------------------------------- |
| 登录失败                   | 站点与租户、账号状态、密码；重试过多时等待限流恢复   |
| 菜单或按钮不可见           | 角色是否启用、是否获得菜单/按钮权限，刷新会话信息    |
| 同事能看到但自己看不到记录 | 部门归属和角色数据范围；不要共享他人账号             |
| 系统设置无法保存           | 编辑权限、字段校验、并发冲突；访问保护还要求系统身份 |
| 设置了参数却不生效         | 是否有业务代码读取，是否误把内置设置放进自定义参数   |
| 文件被拒绝或返回 413       | 场景格式、文件内容、单文件大小及整个请求大小         |
| AI 没有助手、模型或工具    | 显式授权、模型策略、角色绑定和启用状态               |
| AI 或请求限流返回 503      | 部署开关或依赖服务状态，需要部署者排查               |

反馈问题时提供产品版本、操作步骤、发生时间、错误码及脱敏截图。不要提供密码、Token、完整配置文件或他人的业务数据。升级后出现问题，请让部署者核对[版本与兼容关系](../reference/versions)。
