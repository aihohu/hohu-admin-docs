# hohu dev

在一个终端启动组件开发服务，合并显示带组件前缀的日志。命令在前台持续运行，适用于本机开发。

## 前提条件

完成 [`hohu init`](./init)，数据库、Redis 和配置可用。在项目根目录或子目录运行。

## 用法与参数

```bash
hohu dev [OPTIONS]
```

| 参数                  | 说明                        | 默认值             |
| --------------------- | --------------------------- | ------------------ |
| `--only` / `-o`       | 仅启动指定组件，可重复      | 项目声明的全部组件 |
| `--skip` / `-s`       | 跳过指定组件，可重复        | 不跳过             |
| `--app-target` / `-t` | App 目标：`h5`、`mp`、`app` | `h5`               |

| 组件    | 接受的名称，大小写不敏感 |
| ------- | ------------------------ |
| Backend | `backend`、`be`、`admin` |
| Web     | `frontend`、`fe`、`web`  |
| App     | `app`                    |

同时指定 `--only` 和 `--skip` 时，先选入再排除；被跳过的组件不启动。仅筛选已有组件，不下载源码。当前未知名称会被忽略，请核对启动列表。

## 常用示例

```bash
# 全部开发服务
hohu dev

# 仅 Backend + Web
hohu dev --only backend --only web

# 跳过 App
hohu dev --skip app

# 仅 App 微信小程序目标
hohu dev --only app --app-target mp
```

`h5`、`mp`、`app` 分别调用 App 的 `pnpm dev`、`pnpm dev:mp`、`pnpm dev:app`。小程序和原生 App 仍需相应平台工具；CLI 不自动启动微信开发者工具或完成原生打包。

## 确认启动与停止

日志按 `[Backend]`、`[Frontend]`、`[App]` 标记。标准 Web 默认地址为 `http://localhost:9527`，后端为 `http://127.0.0.1:8000`，接口文档为 `http://127.0.0.1:8000/docs`；实际地址以组件输出为准。

打开 Web 并完成登录，确认前后端连接。开发后端默认设置 `APP_ROLE=all`，在单进程中同时运行调度器；生产方式见[部署指南](../deploy)。

在启动终端按 **Ctrl+C**，CLI 会终止它启动的子进程。

## 排错

| 现象               | 处理方式                                   |
| ------------------ | ------------------------------------------ |
| 没有组件启动       | 核对项目标记、筛选名称和相互排除的参数     |
| 某组件被跳过       | 检查源码目录与启动命令，修复后重试         |
| 端口占用或进程退出 | 阅读对应组件日志，检查端口和配置           |
| Web 正常但登录失败 | 确认 Backend 可用，核对 Web 服务地址与代理 |

部分组件失败时，其他组件可能仍在运行。先按 Ctrl+C，再修复并启动；更多问题见[配置与排错](./configuration)。
