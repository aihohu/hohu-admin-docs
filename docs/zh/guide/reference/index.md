# 参考资料

本部分用于开发和运维时快速查询。首次安装看[部署与运维](../operations/)，开发业务功能看[开发指南](../development/)。

| 要查什么                       | 入口                                     |
| ------------------------------ | ---------------------------------------- |
| 组件版本、发布说明、升级记录   | [版本与发布](./versions)                 |
| 参数在哪里配置、何时生效       | [配置参考](./configuration)              |
| OpenAPI、认证、响应和分页      | [API 参考](./api)                        |
| 设置读写、并发、邮件和上传约束 | [设置接口与上传策略](./settings)         |
| HTTP 状态、响应解析和重试      | [错误处理](../backend/error-code)        |
| 按业务场景定位错误             | [常见错误码](../backend/error-code-list) |
| 源码、许可和问题反馈           | [源码与许可](../src)                     |

接口与参数以目标版本的源码和 OpenAPI 为准；本站说明跨接口规则和操作方法，不维护重复的完整接口清单。记录运行版本后再对照资料，避免把开发分支的新能力当作已部署功能。
