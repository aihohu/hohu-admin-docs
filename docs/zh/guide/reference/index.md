# 参考资料

参考页供查询已知功能，不替代入门和实际操作流程。

- [更新说明](./versions)：查阅各组件的正式发行记录与升级说明。
- [配置项归属](./configuration)：决定使用环境配置、系统设置还是每模型配置。
- [设置接口与上传策略](./settings)：分组读写、并发版本、敏感值和资源限制。
- [API](./api)：实际实例的 OpenAPI 及基础响应约定。
- [CLI](../cli/index)：创建、初始化、开发、构建、部署和迁移命令。
- [错误处理](../backend/error-code)与[常见错误码](../backend/error-code-list)：稳定错误标识与排查方向。

代码仓库中的贡献规范、安全政策、ADR 和迁移维护约束通过[源码入口](../src)访问。功能字段变更时先更新代码定义和测试，再同步相关参考；人工摘录不会被标为完整的自动生成 API 清单。
