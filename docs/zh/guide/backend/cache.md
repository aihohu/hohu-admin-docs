# 缓存

普通业务缓存工具位于 `app/core/cache.py`，提供读取、写入、删除及装饰器。普通缓存故障可降级，不代表鉴权、限流、锁和幂等状态也可以无保护放行。

## 租户命名空间

租户数据缓存键使用 `app/core/tenant_scope.py` 的 `tenant_cache_key(tenant, namespace, *parts)`，将租户、用途和资源标识纳入键。不能使用所有用户共享的 `user:{id}` 或不带 tenant 的参数缓存。

查询缓存前仍需验证当前授权；撤权后的用户不能因缓存命中继续获得旧结果。写入并提交成功后，清理对应租户和用途的缓存；Service 不 commit，避免在事务失败前提前清理或发布新值。

## 场景差异

- 展示数据缓存可按工具约定回源数据库。
- HTTP 请求限流使用独立 Redis 原子计数：超额返回 429，存储故障返回 503。
- AI 确认、锁和幂等是执行正确性状态，按各自协议处理断连与恢复，不能套用普通缓存降级策略。

测试跨租户同名键、提交失败、缓存失效和 Redis 故障。详细配置见[配置归属](../reference/configuration)。
