# AI 辅助开发

AI 编程工具可以辅助阅读、实现和测试，但生成内容仍需遵守当前代码契约。不要把聊天中的设计方案自动当成已实现功能。

1. 提供目标、验收标准及相关模块，先阅读仓库 AGENTS/CLAUDE 和维护文档。
2. 新功能或重构先确认设计与权限范围；让实现保持 API → Service → Model 分层。
3. 检查生成的代码是否带可信 tenant、功能权限、数据范围，是否误用废弃配置或接口。
4. 运行真实的静态检查和回归测试，审核 diff；未执行的部署或浏览器验证不能写成已通过。
5. 将已落地行为整理为正式文档，个人提示词、草稿和调试记录保存在构建源目录之外。

不得向工具上下文无必要地提供生产密码、Token 或用户数据。提交、推送和发布遵循仓库授权流程，不因代码生成完成就自动执行。

从[新增业务模块](./development/module)开始，功能完成后同步对应用户手册。
