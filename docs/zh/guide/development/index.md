# 开发指南

从一个业务模块开始，将模型、接口、页面和权限连起来。本指南面向开发者；系统日常操作见[使用指南](../user/index)，服务器发布见[部署与运维](../operations/index)。

## 第一次开发

1. **运行项目**：按[开发环境](../quick-start)创建 Backend 和 Frontend，完成初始化与首次登录。
2. **完成一个模块**：跟随[业务便签教程](./module)，实现创建、分页查询、菜单与中英文页面。
3. **验证并交付**：用普通角色验证功能权限和租户隔离，再按[调试与验证](./testing)检查迁移、构建与操作结果。

便签教程提供完整源码示例。它采用租户共享的数据策略；个人私有或部门共享的业务，需要另外接入相应的数据范围。

## 使用 AI 辅助开发

先[安装 HoHu Skills](../cli/skills)，再让编程助手按 [AI 辅助开发](../ai-coding)创建项目或开发业务模块。生成的代码仍需执行迁移、权限与功能验证。

让应用内 AI 助手使用业务能力时，继续[业务工具接入](./ai-tools)。已有 HTTP 接口不会自动成为 AI 工具；查询、确认执行和结果展示需要单独接入。

## 开发约定

- API 负责认证、权限与事务提交，Service 负责业务逻辑和数据范围，Model 与 Schema 分别定义持久化和接口数据。
- 租户上下文来自服务端认证结果；所有业务查询、关联与写入都要保持租户边界。
- ID 以字符串传给前端，业务类型与菜单权限码保持稳定，中英文资源同步维护。
- 组件版本与检查命令以各仓库的依赖清单、锁文件和贡献说明为准。源码入口见[源码与许可](../src)。
