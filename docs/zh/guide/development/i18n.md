# 国际化

内置文案通过稳定翻译键展示，不在初始化时按部署语言复制多份业务数据。用户填写的品牌、名称、协议和业务内容原样保存。

## 内置数据

菜单使用 `i18n_key`，角色和 Agent 使用 `i18n_keys` 元数据。API 提供原始内容与翻译元数据，客户端只改变展示，不把译文提交回编辑接口。用户修改名称或说明后移除相应翻译绑定；重复种子不能恢复已明确自定义的字段。

旧数据只在仍等于内置默认文案时补翻译键。语言优先级为用户选择、租户默认、部署 `DEFAULT_LOCALE`；缺失翻译回退英文和原文。

## 增加语言

1. 在客户端 locale 注册表和语言选择列表加入语言。
2. 补齐常规界面、`builtin-*` 与 `settings-*` 资源中的相同键，更新资源完整性测试。
3. 在后端设置目录的默认语言选项中注册相同语言代码，按需调整部署默认值。
4. 验证界面切换、表格中的内置名称、缺失键回退、自定义名称与重复初始化。

无需增加第二份初始化数据或按语言扩展业务主键。错误展示使用稳定 `errorCode`，而非把后端 msg 当作语言资源键。多语言业务内容是独立产品需求，不能用界面翻译隐式改写用户数据。
