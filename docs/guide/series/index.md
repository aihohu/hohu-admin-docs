# Documentation series

| Series | Current status                          | Manuals                                 | Upgrade and recovery                                 |
| ------ | --------------------------------------- | --------------------------------------- | ---------------------------------------------------- |
| 0.1    | Maintained; latest formal product 0.1.6 | [0.1 manuals and archive](0.1/index.md) | [0.1 upgrade and recovery](../operations/upgrade.md) |

Existing user, development, CLI and operations URLs continue to belong to 0.1. Changes for 0.2 use a separate directory. Switching series opens its overview; it does not assume equivalent operations or matching pages exist. The language menu switches between the same page in English and Chinese.

No 0.1 EOL countdown has started. The next series must be released, an applicable upgrade path available, and an EOL announcement published before the limited-maintenance period starts. Series manuals and immutable release snapshots remain available after maintenance ends.

[Release notes](../reference/versions.md) track current product status; immutable `release.json` files record published artifact facts. Publishing documentation does not release a product. App/Desktop remain unreleased; CLI versions and supported operations are managed independently.
