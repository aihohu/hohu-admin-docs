## 0.1.6 release snapshot

The [immutable product manifest](https://github.com/aihohu/hohu-admin/releases/download/v0.1.6/release.json) binds final Backend/Web artifacts, CLI, platforms and documentation. The [fixed documentation snapshot](https://github.com/aihohu/hohu-admin-docs/tree/b893371dd1376ddf268bd239d1526715679d610d/docs) preserves release-time text. The live site can still receive wording and security corrections without overwriting historical manifests or tags.

0.1.6 was validated on `linux/amd64` with CLI `0.1.16`, manual digest pinning, and upgrade/recovery from `0.1.5`. Accessible manuals do not expand support to other platforms, sources or clients. See [release notes](../../reference/versions.md).
