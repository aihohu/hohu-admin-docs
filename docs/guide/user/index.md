# User guide

This guide is for people using an installed system. It does not require writing code or running database scripts.

1. Obtain the site address, account and tenant from your administrator, then follow [Account and sign-in](./account).
2. Administrators assign access through [Users, roles and departments](./access). Users see only authorized features.
3. Configure branding, accounts, language and file policies in [System settings](./settings). Manage business parameters separately in [Custom parameters](./parameters).
4. Check your permissions before using [Files and uploads](./files) or the [AI assistant](./ai).

For access problems, see [Troubleshooting](./faq). To install a system, use [Deployment](../operations/index); to extend it, use [Development](../development/index).
