# User guide

This guide is for people using a deployed HoHu instance. Ask your administrator for the site address and tenant. To install your own instance, start with [Deployment](../operations/index).

## First use

1. Open the correct site and sign in with the account provided by your administrator, or register if the site allows it.
2. Check your profile and recovery email. Change an initial password provided by an administrator.
3. Open an authorized business application from the menu. Registration does not automatically grant business access; ask an administrator to assign a role if no business menus are available.
4. Check [Troubleshooting](./faq) when something goes wrong. Include your steps and the error message when reporting a problem.

## Administrator setup

Follow [Set up members and access](./access): create departments, configure roles, then create users. Prepare departments and roles before a bulk import and download a fresh template. Configure [email and account self-service](./settings#account-self-service) before opening registration.

Pages and action buttons depend on your permissions. Ordinary users do not need to manage system settings or obtain deployment configuration files.

Read the [Introduction](../introduction) for product background or try the [Live demo](../show). For business extensions and code integration, see [Development](../development/index).
